# Identifikasi Library, Komponen, dan Framework

## Backend
- Express: framework HTTP server.
- mysql2: akses basis data MySQL.
- cors: pengaturan CORS.
- body-parser: parsing JSON request.

## Frontend
- Bootstrap: layout dan komponen responsif.
- Bootstrap Icons dan Boxicons: ikon UI.
- Swiper, Animate.css, GLightbox: elemen interaktif/visual.

## PWA Komponen
- manifest.json: metadata aplikasi installable.
- sw.js: strategi cache dan fallback offline.
- register-sw.js: registrasi service worker.

## Tooling
- scripts/analyze.js: static checks.
- tests/smoke.test.js: smoke tests.
